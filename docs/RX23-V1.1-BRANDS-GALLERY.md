# RX23 v1.1 - BrandsGallery

## Objetivo
Agregar una nueva sección opcional reutilizable para mostrar marcas representadas y equipos/instrumentación sin acoplarla a un cliente concreto.

## Arquitectura
La sección sigue el mismo patrón del resto de la plantilla:

- src/data: define contenido configurable y flags
- src/types: define contratos del modelo
- src/sections: implementa la presentación
- src/components: reutiliza componentes base como Section y SectionTitle
- src/styles: mantiene estilos base y animaciones reutilizables

## Feature flag
Se agrega el flag `gallery` al modelo de `FeatureFlags` en src/types/index.ts y al archivo src/data/features.ts.

Uso:

```ts
export const features: FeatureFlags = {
  about: true,
  services: true,
  industries: true,
  projects: true,
  differentiators: true,
  gallery: false,
  whatsapp: true,
  socialLinks: true,
  contactForm: false,
  maps: false,
};
```

## Modelo de datos
Archivo: src/data/gallery.ts

```ts
export const gallery: GalleryContent = {
  brandsTitle: 'Marcas representadas',
  productsTitle: 'Equipos e instrumentación',
  brands: [],
  products: [],
};
```

Estructura:

```ts
export interface BrandItem {
  name: string;
  logo: string;
}

export interface ProductItem {
  title: string;
  image: string;
}

export interface GalleryContent {
  brandsTitle: string;
  productsTitle: string;
  brands: BrandItem[];
  products: ProductItem[];
}
```

## Cómo agregar marcas
En src/data/gallery.ts, completa el array `brands`:

```ts
brands: [
  { name: 'Marca A', logo: '/ruta/logo-a.svg' },
  { name: 'Marca B', logo: '/ruta/logo-b.svg' },
]
```

## Cómo agregar equipos o instrumentación
En src/data/gallery.ts, completa el array `products`:

```ts
products: [
  { title: 'Medidor 1', image: '/ruta/producto-1.jpg' },
  { title: 'Sistema 2', image: '/ruta/producto-2.jpg' },
]
```

## UX y comportamiento
- Carrusel horizontal infinito.
- Duplicación de elementos para evitar saltos.
- Animación continua con CSS keyframes.
- Pausa al pasar el cursor.
- Sin botones, flechas o controles.
- Responsive por defecto.

## Integración
La sección se ubica en HomePage después de Projects y antes de Contact, y depende del feature flag `gallery`.

## Accesibilidad
Todas las imágenes incluyen `alt`:
- `alt={brand.name}`
- `alt={product.title}`

## Recomendación
Mantener la sección habilitada solo cuando exista contenido real en src/data/gallery.ts para no renderizar bloques vacíos.
